# 12-Week Phishing Research Tracker

## Run it
1. Extract this ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Tick tasks as you complete them. Progress is saved in that browser on that device.

## Backup and restore
- Use **Export progress (JSON)** to save a backup.
- Use **Import progress** to restore a previously exported JSON backup.

## Install-like desktop access on Windows
For easy access, right-click `index.html` and choose **Show more options → Send to → Desktop (create shortcut)**, or create a desktop shortcut to the file. You can then open the tracker like a local app.

This is an offline browser app; it does not upload your progress. The browser stores progress locally. Clearing browser site data may erase it, so export backups occasionally.
